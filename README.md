💧 Water Billing System (Frontend)

📖 Description
This is the frontend of the Water Billing System. It allows users to interact with the system through a user-friendly interface to manage water billing operations such as login, viewing data, and performing actions.

Technologies Used
- HTML
- CSS
- JavaScript


🚀 Features
- User Login Page
- Dashboard Interface
- API Integration with Backend
- Authentication Handling
- Responsive UI Design

---

 📂 Project Structure
- `index.html` → Main page
- `login.html` → Login interface
- `app.js` → Main logic
- `auth-guard.js` → Authentication handling
- `style.css` → Styling


🔗 Backend Integration
This frontend communicates with the backend using REST APIs built with Spring Boot.

👉 Backend Repository:  
(waterbilling- backend)

 How to Run
1. Download or clone the project
2. Open `index.html` in your browser
3. Make sure backend server is running
4. Start using the system
 ⚠️ Requirements
- Backend API must be running
- Browser (Chrome recommended)
